# Jarvis Voice Assistant

Простой голосовой помощник на Python для Windows, который:
- слушает голос пользователя;
- распознаёт речь через Google Speech Recognition;
- озвучивает ответы через pyttsx3;
- открывает браузер, папки, калькулятор и блокнот;
- поддерживает базовые команды на русском языке.

## Что умеет
- "Привет"
- "Открой браузер"
- "Открой YouTube"
- "Открой Яндекс"
- "Открой папку документы"
- "Открой папку загрузки"
- "Открой калькулятор"
- "Открой блокнот"
- "Время"
- "Дата"
- "Выход"

## Требования
- Windows 10/11
- Python 3.9+
- Микрофон
- Интернет для распознавания речи через Google

## Установка

1. Скачайте проект.
2. Откройте терминал в папке проекта.
3. Установите зависимости:

```bash
pip install -r requirements.txt
```

## Запуск

```bash
python main.py
```

## Возможные проблемы
- Если `pyaudio` не устанавливается, установите Microsoft C++ Build Tools.
- Если распознавание не работает, проверьте микрофон и интернет.
- Если `PyAudio` не ставится на Python 3.12, используйте Python 3.10/3.11.
